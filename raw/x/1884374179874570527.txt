Let's build a Deepseek Wrapper (Mobile App) without writing a single line of code!

Everyone is talking about building web apps with AI, but no one is talking about building mobile apps. 

This video tutorial and @senior_swc template (built by 
@anshnanda ) will help you get starting building an app on iOS. This is react native so it's also compatible with Android and Web (But we will cover this in a future video). 

The point of this video is to get some experience in the simulator and to start building an app. In a video, soon, we will take the app we've built, test it on our phone, and put it on Test-Flight! (Without writing ANY code!)

Just a warning:
The DeepSeek API has been tough to rely on.
So I decided to add Gemini into my app as a backup, which you can do as well (with any AI model)
