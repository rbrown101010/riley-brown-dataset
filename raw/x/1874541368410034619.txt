I built an AI powered writing app with Cursor Agent without writing a single line of code in a little over an hour.

Features: 
- AI powered autocomplete
- AI powered image search with autosuggestions based on what i'm writing
- Ai powered research based on what i'm writing
- Block based writing (which is useful for my workflow as a video content creator)

!!! And I ran it locally this time.
Normally I use replit, so if you got stuck on connecting cursor and replit, this video is for you.

Template pinned on @senior_swc (starting point you can download)

Tools used
- Cursor (Claude for ai model)
- Firebase 
- Deepseek @deepseek_ai 
- Exa ( @ExaAILabs )
- Search API

These videos serve as R&D for the app we're building at @yapthread. We're building the cursor for content creators.
